## Key Learnings

- `print()` displays output.
- Variables store values.
- `type()` checks the data type of a value.
- Python number types include `int`, `float`, and `complex`.
- Python supports arithmetic operators such as `+`, `-`, `*`, `/`, `//`, `%`, and `**`.
